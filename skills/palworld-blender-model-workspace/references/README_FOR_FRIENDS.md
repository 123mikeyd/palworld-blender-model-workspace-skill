# Share this skill with another Hermes user

This package contains instructions only—no Palworld assets, Paks, textures, or game files.

## Windows installation

1. Unzip the `palworld-blender-model-workspace` folder into:
   `%LOCALAPPDATA%\hermes\skills\game-dev\`
2. The final file must be:
   `%LOCALAPPDATA%\hermes\skills\game-dev\palworld-blender-model-workspace\SKILL.md`
3. Start a new Hermes chat/session. Ask: “Help me make a Blender workspace from my own Palworld model.”

Each person must install UEFormat and extract their own legal local-game assets. Do not share extracted Palworld files through this skill package.

## What it helps an agent do

- locate/verify the UEFormat Blender importer
- explain the FModel → `.uemodel` → Blender path
- create a safe texture-paint workspace using copied body textures
- preserve bones/rest pose and hand off correctly to a UE5.1 packaging workflow
